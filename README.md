# 👮‍♀️ Women Safety App

A mobile-first safety companion app designed to enhance the personal security of women by providing **safe zones**, **safe route recommendations**, and **crowdsourced safety ratings**.

> 🚀 Developed as part of a student innovation initiative. Built with modern web technologies for real-world impact.

---

## 🔧 Tech Stack

- **Frontend**: React.js, Bootstrap, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **APIs**: Google Maps API, Custom Safety APIs
- **Others**: Geolocation API, JWT Authentication

---

## 💡 Features

- 🛡️ **Safe Zones**: View nearby areas with high safety scores.
- 🗺️ **Safe Routes**: Get optimized travel paths with better security and lighting conditions.
- 🧭 **Location Tracking**: Real-time location sharing with emergency contacts.
- ✍️ **User Reviews**: Rate and review the safety of locations to inform others.
- 📍 **Panic Button**: One-tap emergency alert with location sharing.
